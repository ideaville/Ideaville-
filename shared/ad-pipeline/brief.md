# Ideaville — 10s polished ad brief

## Product
Ideaville / Alpha Performance Solutions — live MHCLG EPC tooling for Greenwich & SE London: look up certificates, flag retrofit need, screen grant/scheme fit.

## Deliverable
Polished **10-second** promotional ad: motion design + implementation code that renders/exports the cut.

## Creative
- One composition, brand-first (Ideaville as hero signal)
- One headline, one short support line, one CTA
- Real visual anchor: SE London / Greenwich home energy context (not abstract purple AI gradients)
- 2–3 intentional motions only; no card clutter, no dashboard chrome
- Tone: civic, confident, practical

## Beats (10s)
| t | beat |
|---|------|
| 0.0–2.0 | Brand + atmosphere: Ideaville over a real place feel |
| 2.0–5.5 | Problem → clarity: EPC / retrofit uncertainty → live register truth |
| 5.5–8.5 | Product moment: lookup / band / scheme lead in motion |
| 8.5–10.0 | CTA lockup |

## Shared sync
Assets and code stay in this folder (`shared/ad-pipeline/`) so GrokBot (motion/orchestration) and Claude Code (implementation) stay in sync.
